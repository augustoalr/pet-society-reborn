## Instrucciones de la tarea
1. Crea y cambia a la rama `t-03-motor-grafico`.
2. Implementa la lógica de cálculo y escalado responsive en `src/game/viewport/`:
   - Define constantes de resolución virtual fija (ej. `VIRTUAL_WIDTH = 800`, `VIRTUAL_HEIGHT = 600`, aspecto 4:3).
   - Crea una función pura `calculateViewportScale(containerWidth: number, containerHeight: number)`:
     - Calcula el factor de escala uniforme para ajustar el lienzo al contenedor sin recortar ni deformar (modo "fit" / aspect-ratio preserved).
     - Retorna `{ width, height, scale, offsetX, offsetY }`.
     - Añade tests unitarios para esta función en `src/game/viewport/__tests__/calculateViewportScale.test.ts`.
3. Crea el wrapper del motor gráfico en `src/game/engine/PixiGameEngine.ts`:
   - Clase que encapsula la instancia de `Application` de PixiJS v8.
   - Método `async initialize(container: HTMLElement): Promise<void>`:
     - Inicializa `Application` con `await app.init({ width, height, resolution: window.devicePixelRatio || 1, autoDensity: true, backgroundColor: 0x87CEEB })`.
     - Añade `app.canvas` al contenedor DOM.
     - Configura el contenedor principal (`app.stage`) para interactividad y eventos de puntero (`eventMode = 'static'`).
   - Método `resize(containerWidth: number, containerHeight: number): void`:
     - Aplica el escalado calculado por `calculateViewportScale`.
   - Método `destroy(): void`:
     - Limpia la aplicación de PixiJS (`app.destroy(true, { children: true })`) liberando memoria y evitando fugas de WebGL.
   - Abstracción de eventos de puntero: registra y despacha eventos unificados de pointerdown/pointerup sobre el escenario virtual.
4. Crea el componente React en `src/ui/components/GameCanvas.tsx`:
   - Monta el contenedor donde se inserta el Canvas de PixiJS.
   - Usa un `ResizeObserver` (con debounce o RAF) y listener de `resize` para llamar a `engine.resize()`.
   - Maneja ciclo de vida seguro de React 19: inicializa el motor una sola vez y lo destruye limpiamente en el return del `useEffect`.
   - Muestra un estado de carga mientras `app.init()` se resuelve.
5. Integra `GameCanvas` en `src/ui/App.tsx`:
   - Muestra el HUD superior / contenedor y el lienzo centrado.
6. Exporta limpiamente los módulos desde `src/game/index.ts` y `src/ui/index.ts`.
7. Ejecuta `npm run verify` localmente y asegura que linter, tipos (`tsc --noEmit`), tests y build terminen con éxito (código 0).
8. Commit Conventional Commits: `feat(T-03): motor grafico 2d y lienzo responsive`.
9. Abre el PR hacia `main` con el título `T-03: motor grafico 2d y lienzo responsive`.
